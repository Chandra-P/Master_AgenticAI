---
name: Movie catalog policy
description: Release-status policy for updates to the built-in movie library.
---

When refreshing the built-in library with recent movies, include released films with verified release years rather than treating announcements as completed releases.

**Why:** The previous library included an upcoming film under an assumed release year. That can give players misleading movie choices.

**How to apply:** Check release status and the actual year when adding current-year titles; leave announced-only films out of the default random pool.
