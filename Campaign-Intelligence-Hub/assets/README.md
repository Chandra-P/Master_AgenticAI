# App background

`architecture-background.png` was created using the built-in image-generation tool.

Prompt: sophisticated wide photograph of quiet modern glass architecture through frosted glass; ivory and pale-gray negative space across the left and middle, understated navy and muted-teal reflections at the right edge. Low contrast for white analytical cards. No text, logos, numbers, graphs, people, or interface elements.

The app loads this local decorative image once per process cache and applies a readability overlay. No external image service is required.
