# KidSpark video demo script

## 1-minute opening

"Hi everyone, this is KidSpark. It’s a browser-based learning app for middle and high school students that turns real-world decisions into short, engaging challenges. Students get to practice budgeting, scam awareness, and event planning in a low-pressure, game-like environment that feels more like a learning adventure than a worksheet."

## 2-minute project overview

"I built KidSpark to help students practice skills they actually need in everyday life. Instead of reading a long lesson, students move through short scenario-based decisions, get immediate feedback, and see how their choices connect to real-world outcomes. The app includes guided choices, hints, explanations, saved progress, and a progress dashboard so students can keep building their understanding over time."

## 1-minute workflow with AI tools

"I used AI-assisted coding tools as part of the development workflow. In VS Code, I used GitHub Copilot and other AI coding support to scaffold the app structure, generate the challenge logic, draft the educational content, and iterate on the user experience quickly. I also used AI to help refine the prompts, fix bugs, improve the app flow, and check logic against the tests. That let me move faster while still validating the behavior with real code and test runs."

## 2-minute live demo

"Here’s how the app works in practice. I start by entering a nickname and choosing a challenge. I can select a level, start a round, and answer each decision with the best choice based on the scenario. If I want help, I can open the hint and read the explanation before moving on. After the round, the app saves the result and shows my progress, scores, and recommendation for the next challenge."

"The project is built in Python with Streamlit, and the data is stored locally so student progress can persist in a simple demo environment. I also included a leaderboard and history views so learners can see their improvement and compare results within a safe, fictional profile system."

## 30-second close

"The key idea behind KidSpark is that learning becomes more engaging when students make decisions in realistic situations and get immediate feedback. AI helped speed up the build process, but the final app still relies on thoughtful content design, testing, and user-focused iteration to make it useful and credible."
